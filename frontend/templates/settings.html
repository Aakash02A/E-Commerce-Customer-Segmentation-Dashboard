About

A data-driven E-Commerce Customer Segmentation & Analytics Dashboard. Upload your own transaction dataset, map columns to a standard schema, validate data quality, and run RFM segmentation with PySpark.

This is a local, single-user application. It is not a multi-tenant production service and does not include authentication.

Data Pipeline

  1. Upload → File Validation
  2. Column Detection → Mandatory Column Mapping → User Confirmation
  3. Data Quality Validation → Schema Normalization
  4. PySpark Processing → RFM Analysis → Segmentation
  5. Dashboard → Export
